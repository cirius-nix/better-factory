# req-review-report: One design review with a report

**Master:** [Requirements](README.md)
**Context:** context-factory
**Priority:** Must

## Statement

The project must review each design with one procedure that writes a report
with findings and makes no edits.

## Acceptance criteria

- Given a design ready for review, when the reviewer runs the review procedure, then the procedure writes a report with findings.
- Given a completed review, when the reviewer reads the design, then the design holds no edits from the review.

## Notes

- The report format belongs to later phases (P2+).
